First Tech Federal Credit Union is a federally chartered, member-owned, not-for-profit financial cooperative headquartered in San Jose, California, and one of the largest credit unions in the United States. Founded to serve employees of the technology industry and their families, it is NCUA-insured and provides consumer and business banking, lending, mortgages, credit cards, and wealth services through its website and mobile apps.

## Open Finance / API Posture

Like the vast majority of US credit unions, First Tech Federal publishes **no first-party public developer portal or documented open API**. Consumer-permissioned financial data sharing is handled through third-party data aggregators (Plaid, MX, Finicity, Akoya) rather than a directly documented first-party API surface.

US open finance is voluntary and fragmented. The Financial Data Exchange (FDX) standard and the CFPB's Section 1033 Personal Financial Data Rights rule are still emerging. No first-party FDX-conformant data-access API and no published Section 1033 posture were found for First Tech during this review. This is an identity-only record: honest, non-fabricated, with an empty `apis[]` because no public API surface exists.
